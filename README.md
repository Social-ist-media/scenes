# Sensory

A live dream studio. Weave a shared room by hand: a three-dimensional field, sound and story layers, a temporal record, and a small creator economy paid in studio credit.

## Rooms

- **Palace** — the rooms you keep
- **Studio** — a live session with phases, presence, and the loom
- **Atlas** — the field of motifs
- **Market** — effects you can buy
- **Ledger** — what the room earned

## Run

```bash
npm install
npm run dev
```

The dev server listens on port 8080.
